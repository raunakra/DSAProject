## ⚙️ How to Deploy

### Quick Start (3 steps)

**1. Commit and push changes:**
```bash
cd c:\zProjects\Zinterview\DSAProject
git add .
git commit -m "Add GitHub Pages configuration"
git push origin main
```

**2. Enable GitHub Pages:**
- Go to: https://github.com/raunakra/DSAProject/settings/pages
- Source: `Deploy from a branch` → `main` `/root`
- Or use `GitHub Actions` (auto via workflow)
- Click Save

**3. Wait for deployment:**
- Check: https://github.com/raunakra/DSAProject/actions
- Green checkmark = deployed ✅
- Site goes live at: https://raunakra.github.io/DSAProject
